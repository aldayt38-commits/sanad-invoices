# ذِمّتي 📒 — دفتر الديون الذكي

**تطبيق ويب عربي (PWA)** لتسجيل الديون الشخصية: من مين وبكم — ليّا عليه أو أنا عليه — مع تصنيفات ومواعيد استحقاق، ومشاركة بلمسة عبر واتساب. **يشتغل محليًا بلا تسجيل**، ولو سجّلت دخول بحسابك **كلشي بيتزامن سحابيًا ويرجع معك من أي جهاز**.

> - **فحوى الجدوى:** https://aldayt38-commits.github.io/sanad-invoices/jadwa.html

## ✨ المزايا

**الأساسي:**
- ➕ أشخاص: **ليّا عليه** / **أنا عليه** بمبلغ وملاحظة · 💸 دفعات جزئية + تسديد كامل + سجل زمني
- 🔍 بحث + فِلترات (الكل / ليّا / عليّ / متأخرات / مسدّد)
- 🌓 مظهر فاتح/داكن ·8 عملات · ⬇️⬆️ تصدير/استيراد JSON
- 📴 PWA يعمل بدون إنترنت وقابل للتثبيت · 🔒 بلا تتبع ولا إعلانات

**الحساب والمزامنة (v1.2):**
- 🔑 **تسجيل دخول بجيت هوب (GitHub)** → ملفك السحابي الخاص (Secret Gist) → الدخول من جهاز تاني بيرجّع كل الناس والسجلات والتصنيفات — **إلّا لو حذفتها بنفسك**
- 🔄 مزامنة تلقائية بعد كل تعديل (debounce) + حالة ظاهرة (آخر مزامنة/بانتظار/خطأ)
- 🚪 خروج آمن: مزامنة أخيرة ثم مسح محلي (البيانات تضل بحسابك)

**التنظيم والتنبيهات (v1.2):**
- 🏷 **تصنيفات مخصّصة** تضيفها بنفسك (البيت، الدكان، …) + فلترة بها + سطرها ببطاقة الملخص
- 📅 **موعد استحقاق** لكل دَين: 🔴 متأخر · ⏰ اليوم · 🟢 باقي X يوم · ✔ انتهى ومسدّد
- ⏰ **شريط المتأخرات** بالرئيسية بضغطة وحدة
- 🔔 **تنبيه متصفح:** «نسيت تسدد دين {الاسم} ({المبلغ})؟ الموعد كان …» — عند الفتح ودوريًا كل6 ساعات
- ✅ **إشعار «تم انتهاء الدين»** للطرف الآخر بعد التسديد (واتساب/بطاقة/نسخ) + زر تذكير 🔔

**حزمة الانتشار (v1.1):**
- 🔗 **رابط طلب موجّه:** يفتح عند الطرف الآخر باسمه ومبلغه — «سجّل في دفترك» بضغطة
- 📊 **بطاقة ملخّص** PNG جاهزة للستوري · 📲 مشاركة النظام · 📥 تثبيت PWA · ✍️ اسمك برسائلك

**إضافات المطوّر:** ↩️ تراجع عن الحذف (7 ثواني) · 📝 ملاحظة على كل دفعة («دفع نقدًا»)

## 🛠️ التشغيل محليًا

```bash
python3 -m http.server 8080 --directory .
# افتح http://localhost:8080
```

لا يوجد Build ولا اعتماديات — كل شيء HTML/CSS/JS خام.

## 🔑 دليل تسجيل الدخول للمستخدم (30 ثانية)

1. افتح **github.com/settings/tokens** → Generate new token (classic)
2. مدة 30 يوم · علّم صلاحية **gist** فقط ✅ → Generate
3. بالإعدادات داخل التطبيق: 🔑 تسجيل الدخول → الصق التوكن → «دخول ومزامنة»

> التوكن بينحفظ بجهازك فقط. التفاصيل التقنية والبدائل: `docs/v1.2-changes-study.md`
