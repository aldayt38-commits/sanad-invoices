# ذِمّتي 📒 — دفتر الديون الذكي

**تطبيق ويب عربي (PWA)** لتسجيل الديون الشخصية: من مين وبكم — ليّا عليه أو أنا عليه — مع تصنيفات ومواعيد استحقاق، ومشاركة بلمسة عبر واتساب. **يشتغل محليًا بلا تسجيل**، ولو سجّلت دخول بحسابك **كلشي بيتزامن سحابيًا ويرجع معك من أي جهاز**.

> ### 🔗 الروابط
> - **الرابط الدائم (GitHub Pages):** https://aldayt38-commits.github.io/sanad-invoices/
> - **لوحة الإدارة (داخليّة — ببوّابة توكن):** https://aldayt38-commits.github.io/sanad-invoices/admin.html
> - **المستودع:** https://github.com/aldayt38-commits/sanad-invoices
>
> 📄 دراسة الجدوى داخلية (`jadwa.html` — بـ noindex وغير مربوطة من الواجهة، روابطها بالمستودع وبلوحة الإدارة فقط).

## ✨ المزايا

**الأساسي:**
- ➕ أشخاص: **ليّا عليه** / **أنا عليه** بمبلغ وملاحظة · 💸 دفعات جزئية + تسديد كامل + سجل زمني
- 🔍 بحث + فِلترات (الكل / ليّا / عليّ / متأخرات / مسدّد)
- 🌓 مظهر فاتح/داكن ·8 عملات · ⬇️⬆️ تصدير/استيراد JSON
- 📴 PWA يعمل بدون إنترنت وقابل للتثبيت · 🔒 بلا تتبع ولا إعلانات

**الحساب والمزامنة (v1.2):**
- 🔑 دخول ظاهر (أيقونة الحساب بالأعلى + بانر بالرئيسية + الإعدادات) بتوكن GitHub → Secret Gist
- 🔄 مزامنة تلقائية بعد كل تعديل + حالة ظاهرة + 🚪 خروج آمن (مزامنة ثم مسح محلي)

**التنظيم والتنبيهات (v1.2):**
- 🏷 تصنيفات حرّة (البيت، الدكان، …) + فلترة · 📅 مواعيد استحقاق (متأخر/اليوم/باقي)
- ⏰ شريط المتأخرات · 🔔 «نسيت تسدد» بتنبيه متصفح · ✅ إشعار «تم انتهاء الدين» بعد التسديد

**حزمة الانتشار (v1.1):**
- 🔗 رابط طلب موجّه · 📊 بطاقة ملخص PNG · 📲 مشاركة النظام · 📥 تثبيت PWA

**إضافات:** ↩️ تراجع حذف · 📝 ملاحظة دفعة · 📢 شريط إعلانات عام يُدار من لوحة الإدارة

## 🛡️ لوحة الإدارة (داخليّة)

- **الرابط:** `admin.html` (غير مربوطة من أي مكان بالواجهة + `noindex`).
- **الحماية:** لا يظهر أي محتوى قبل إدخال **توكن إدارة يخصّك** (يتحقق من الحساب عبر GitHub API) — غيرك ما بيشوف إلا حقل توكن.
- **الصلاحيات المطلوبة للتوكن:** `public_repo` + `gist`.
- **القدرات:**
  1. 📊 نظرة عامة: stars/forks/issues، آخر commit، حالة Pages، إعادة بناء.
  2. 📢 المحتوى العام: تفعيل/تعطيل **شريط إعلان** يظهر لكل الزوار (`site-config.json`).
  3. 🗄 البيانات: إحصاءات وجدول أشخاص، رفع/سحب/استرجاع نسخ سحابية (Gist)، تصدير، تفريغ.
  4. 🩺 فحص الموقع: فحص كل المسارات (200/404) + محتوى الإعداد.
  5. 🔒 داخلية: روابط دراسات الجدوى.

## 🔑 دليل تسجيل الدخول للمستخدم (30 ثانية)

1. افتح **github.com/settings/tokens** → Generate new token (classic) → مدة30 يوم
2. علّم صلاحية **gist** فقط ✅ → Generate
3. داخل التطبيق: أيقونة **الحساب** (أعلى) أو بانر ☁️ → الصق التوكن → «دخول ومزامنة»

> التوكن بينحفظ بجهازك فقط. التفاصيل: `docs/v1.2-changes-study.md`
