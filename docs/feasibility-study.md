## 1. الفكرة

**ذِمّتي** — دفتر اديون شخصي عربي بالكامل:

- تسجّل كل شخص: **ليّا عليه** (أخضر) أو **أنا عليه** (أحمر) بمبلغ وملاحظة.
- تسجّل الدفعات الجزئية، وتتابع الرصيد، وتسدّد كامل بلمسة.
- **حلقة الانتشار:** زر «مشاركة/طلب» يولّد رسالة واتساب مهذّبة («يا سامي، بذمتك عندي 750 ₪...») أو **بطاقة صورة جاهزة للنشر** — كل طلب دفع = شخص جديد يتعرّف على المنتج.
- **بدون تسجيل، بدون سيرفر:** كل البيانات داخل متصفح المستخدم (localStorage) + يعمل أوفلاين (PWA).

**لماذا هذا الفكرة على فكرة أخرى؟** اشترطتَ شطرين: تنتشر **وتجيب فلوس**. الألعاب والمولّدات تنتشر بسرعة وتموت بسرعة بلا دخل؛ الأدوات الإنتاجية تعيش بلا انتشار. «ذِمّتي» يجمع الاثنين: ألم يومي + قناة توزيع مدمجة داخل كل عملية + نموذج freemium واضح.

**الجمهور المستهدف أولًا:** فلسطين والأردن ولبنان والعراق ومصر — حيث اقتصاد الكاش والعائلات الممتدة ومجموعات الواتساب هي البنية التحتية اليومية للنقود الصغيرة.

## 2. المشكلة (بأدلة سلوكية، لا تخمين)

1. **الدين الصغيرة جزء من الروتين:** التسليف بين الأهل والأصحاب والأقساط الصغيرة شائع جدًا في العالم العربي، وغالبًا يُدار بـ«ورقة» أو ذاكرة متصفح أو ملاحظة واتساب.
2. **إحراج طلب الفلوس:** الناس تتجنّب تذكير المدين خوفًا على العلاقة → الدين ينسى أو يتكرر الجدل. رسالة مكتوبة مهذّبة من أداة محايدة تحل المشكلة الاجتماعية.
3. **لا وجود لسجل مالي شخصي عربي مبسّط:** البديل الحقيقي اليوم ليس منافسًا — بل «لا شيء منظّم».

## 4. نموذج الانتشار (Viral Loops)

```
┌─────────────────────────────────────────────────────────┐
│  L1 — حلقة طلب الذمة (مدمجة في الاستخدام اليومي)        │
│  مستخدم يسجّل دَين → زر «طلب/مشاركة» → رسالة واتساب      │
│  أو بطاقة PNG → المدين يفتح الرابط → «افتح دفترك أنت»      │
│  → مستخدم جديد → يسجّل ديونه → يشارك ... (تكرار)          │
├─────────────────────────────────────────────────────────┤
│  L2 — حلقة الصورة الاجتماعية                             │
│  بطاقة مشاركة بتصميم عربي جاهزة للستوري/المجموعات        │
├─────────────────────────────────────────────────────────┤
│  L3 — حلقة مجموعة العائلة (v1.1: دفتر مشترك برمز دعوة)   │
│  دعوة عائلية = دخول دفعة مستخدمين دفعة واحدة             │
├─────────────────────────────────────────────────────────┤
│  L4 — البحث العضوي (SEO + متجر التطبيقات كـ PWA)           │
│  نية بحث عالية: «تطبيق حساب الديون بين الأصدقاء»          │
└─────────────────────────────────────────────────────────┘
```

**الخصائص القياسية لحلقة L1 داخل المنتج:**
- زر المشاركة داخل كل ملف شخصي (أول شاشة تُفتح).
- رابط قصير بلا تسجيل (WA deep-link + رابط الموقع).
- نداء فعل واضح على البطاقة: «افتح دفترك أنت كمان».
- الاحتكاك = صفر: فتح الرابط يشتغل فورًا (SPA + أوفلاين).
